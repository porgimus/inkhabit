# Describing how someone writes and takes notes

`<out>/profile.md` holds the measurements: letterforms, joins, spacing, line slope, indentation depth, what
each colour is used for, line patterns, shorthand, and a per-folder table. To redo it for an existing build
without losing the review: `inkhabit profile <sources...> -o <out> --family "<Name> Hand"`.

When the user asks how they write or take notes, the numbers are half the answer. Also look:
`inkhabit pages <one source> -o <dir> --max 2` for three or four sources of different kinds, read the
images, and write what the numbers do not show (layout habits, how colour and arrows are used, look-alike
letters) to `<out>/style-notes.md`. Say which pages you looked at.
